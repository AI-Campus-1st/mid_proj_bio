## 1. 분석 대상 기업 선정

### 1-1. 선정 절차

1. **비교군 구성** — CDMO 사업을 하는 국내 상장사 14곳을 후보로 둔다 (`collect/config.py` 의 `COMPANIES`).
2. **자격 요건** — 분석이 성립하기 위한 최소 조건 3가지를 적용한다.
3. **공시 가중 점수** — 공시 1건마다 유형별 가중치를 붙여 기업별로 합산한다.
4. **최종 판단** — 점수 순위에 본업 점수와 매출 규모를 함께 보고 확정한다.

비상장사(롯데바이오로직스, SK팜테코 등)는 DART 정기공시가 없어 비교군에서 제외했다.

### 1-2. 자격 요건

| # | 요건 | 이유 |
|---|---|---|
| G1 | 기간 내 사업보고서 3건 | 뉴스와 공시의 시점 비교가 3년 전체에서 성립해야 한다 |
| G2 | 불성실공시법인 지정 이력 없음 | 공시 자체의 신뢰도가 분석의 전제이다 |
| G3 | 수주 공시 3건 이상 | CDMO 사업 활동이 공시로 확인되어야 한다 |

### 1-3. 공시 유형별 가중치

기준은 **CDMO 사업과의 직접성**이다. 정정 공시는 같은 사건의 반복이므로 0점으로 처리한다. 분류 규칙은 4절.

| 분류 | 가중치 | 해당 공시 | 근거 |
|---|---|---|---|
| 수주 | 5 | 단일판매·공급계약체결, 위탁생산 계약 | CDMO 매출의 직접 원천. 매출액 대비 일정 비율 이상 계약만 공시 의무 대상 |
| 증설 | 4 | 신규시설투자, 유형자산취득결정 | 생산능력이 수주 상한을 정한다 |
| M&A·구조개편 | 4 | 타법인주식 취득·처분, 회사분할 | 생산거점 인수·분할 등 사업 구조 변화 (`바이오 M&A` 키워드와 대응) |
| 실적 | 3 | 영업(잠정)실적, 손익구조 변동 | 수주가 매출로 전환되는지 확인하는 결과 지표 |
| 임상·허가·기술계약 | 2 | 투자판단 관련 주요경영사항 | 산업 이슈이나 자체 파이프라인 사안으로 CDMO 본업과는 간접 관계 |
| 자금조달 | 2 | 유상증자, 사채 발행 결정 | 증설 재원 (`바이오 투자 유치` 키워드와 대응). 사업 성과 자체는 아니다 |
| 정기보고서 | 1 | 사업·반기·분기보고서 | 모든 상장사 공통이라 변별력이 낮다 |
| IR | 0 | 기업설명회 개최 | 일정 안내일 뿐 사건이 아니며, 개최 횟수가 점수를 왜곡한다 |
| 리스크 | 0 | 소송, 불성실공시, 횡령·배임, 조회공시 | 점수에는 넣지 않고 건수만 따로 표기한다 |
| 기타 | 0 | 지분 변동, 주주총회, 발행 절차 서류 | 사업 이슈와 무관하거나 다른 공시와 중복 |

- **가중 점수** = Σ(가중치 × 건수)
- **본업 점수** = 5 × 수주 건수 + 4 × 증설 건수

### 1-5. 기업별 선정 근거 — "왜 이 기업인가"

**삼성바이오로직스**
- 수주 공시 22건, 본업 점수 110으로 모든 지표에서 1위이다.
- 회사분할 결정(2025-05)과 타법인 주식 취득 등 구조개편 공시도 4건 있다.
- 비교의 기준점이 되는 기업이다.

**프레스티지바이오로직스**
- 수주 공시 15건으로 2위이며, 가중 점수의 77%가 수주에서 나온다. 비교군 중 CDMO 순도가 가장 높다.
- 매출이 125억 원으로 작아 소규모 계약도 공시 대상이 된다는 점은 해석 시 감안한다.

**에스티팜**
- 수주 5건과 실적 공시 16건이 함께 있어, 수주가 실적으로 이어지는 흐름을 볼 수 있다.
- 올리고핵산 원료 CDMO로, 항체 중심인 다른 기업과 모달리티가 다르다.

**SK바이오사이언스**
- 가중 점수는 2위이나 본업 점수는 19로 낮다. 점수 대부분이 실적(15건)과 임상·허가(12건)에서 나온다.
- 따라서 "순수 CDMO"가 아니라 **인수(타법인 주식 취득 2건)와 자체 백신 개발을 병행하는 사례**로 다룬다.

**바이넥스**
- 가중 점수는 46점으로 팬젠(48점)보다 2점 낮아, 점수 순위만으로는 6위이다.
- 그럼에도 5번째 기업으로 유지한 근거는 다음 세 가지이다.
  - 본업 점수가 팬젠보다 높다 (24 대 20).
  - 증설 공시가 있다 (2025-09 신규시설투자). 팬젠은 0건이다.
  - 매출이 약 12배이다 (1,685억 원 대 134억 원). 산업 이슈를 대표하기에 규모가 충분하다.

### 1-6. 선정의 한계

- **가중치는 조에서 정한 판단 기준**이다. 근거는 표에 명시했으나, 수치 자체(5·4·3·2·1)는 통계적으로 추정한 값이 아니다.
- **IR 가중치와 자격 요건은 1차 결과를 본 뒤 조정**했다. IR을 1점으로 두면 에스티팜이 IR 46건만으로 점수의 3분의 1을 얻어 순위가 왜곡되었다.
- **공시 건수는 금액이 아니다.** 수주 공시 의무는 매출액 대비 비율로 정해지므로, 매출이 작은 기업일수록 건수가 많아진다. 계약 금액은 이후 공시 원문에서 정규식으로 뽑아 대시보드 S4에 보완했다 (`analysis/extract_contract_amounts.py`, 수주 공시 98건 중 94건 추출·매출 비율 대조 94/94 일치 — [CONTRACT_AMOUNTS](CONTRACT_AMOUNTS.md)).
- **"일정 비율 이상만 공시 의무"의 정확한 비율**은 거래소 공시규정 원문에서 확인한 뒤 리포트에 인용한다. 현재는 미확인이다.
- **정정 공시를 제외**했기 때문에, 계약 금액이 증액된 정정 건은 선정 점수에 반영되지 않는다 (대시보드 S4 금액은 최신 정정본 금액을 쓴다).
- **뉴스 노출량(기업명 언급 기사 수)은 선정 점수에 반영하지 않았다.** 기업명 뉴스는 선정 뒤 수집했다 (기업별 건수는 [DATABASE_SCHEMA](../06_technical/DATABASE_SCHEMA.md) 4절).

## 2. DART OpenAPI 사용

| API | 용도 | 주요 파라미터 | 저장 위치 | 스크립트 |

| 항목 | 방식 |
|---|---|
| 인증키 | `.env` 의 `DART_OPEN_API` (`collect/config.py` `load_env`, 값은 출력하지 않음) |
| 호출 간격 | 0.3초 (`DELAY = 0.3`) |
| 재시도 | 네트워크 오류 시 최대 3번, 3초 × 시도 횟수만큼 기다렸다가 다시 호출 (`collect_dart_list.py` `get()`) |
| 상태 코드 | `000` 정상, `013` 조회 결과 없음 → 저장. 그 밖의 코드는 저장하지 않고 멈춘다. `014` 파일 없음(원문) → `_missing.json` 에 기록하고 다시 요청하지 않음. `020` 요청 제한 초과 → 기록하지 않고 멈춤(나중에 다시 실행하면 이어서 받음) |
| 이어받기 | 이미 저장한 응답 파일은 건너뛴다. `list_selected/` 의 수집 기간(`bgn_de`·`end_de`)이 설정과 다르면 멈춘다 — 기간을 바꾸면 폴더를 비우고 다시 받는다 |

## 5. 원문 보관과 텍스트 추출

- **보관:** DART가 주는 zip(`document.xml`)을 그대로 `data/raw/dart/document/{접수번호}.zip` 에 둔다. 지분공시 등 유형을 가리지 않고 5개사의 모든 공시를 받았다. 원본은 git에 있다.
- **추출:** `db/build_db.py` `to_text()` — zip 안 파일마다 UTF-8로 읽고 실패하면 CP949로 읽는다. `style`·`script`·주석을 지우고, **표는 행마다 줄바꿈, 칸은 ` | ` 로 구분**해 남긴 뒤 나머지 태그를 걷어낸다. 행 끝의 빈 칸 구분자와 빈 줄은 지운다.
- **순서:** 파일명이 접수번호와 같은 본문을 `seq = 1`, 첨부(감사보고서 등)를 2부터 붙인다 (`disclosure_documents`).
- **원문 누락 3건:** 모두 첨부정정 공시로, DART가 "파일이 존재하지 않습니다"(014)를 반환했다. 사유는 `data/raw/dart/document/_missing.json` 에 남아 있다.
- **쓰임:** 공시 RAG는 `seq = 1` 본문만 청크로 나눠 색인한다(864건 → 청크 36,548개, [NEWS_DISCLOSURE_MATCHING](../04_ai/NEWS_DISCLOSURE_MATCHING.md)). 수주 계약 금액 추출도 본문의 "계약금액" 표 칸을 읽는다.

## 7. 유의점

- **선정 점수(1절)와 DB 분류 결과(4절)는 범위가 다르다.** 선정은 후보 14개사의 `list/` 를 썼고, DB는 5개사의 `list_selected/` 를 쓴다. 기간은 같다(2023-10-19 ~ 2026-10-19).
- **공시 건수는 금액이 아니다.** 대시보드 S4는 건수와 금액을 같은 차트에 섞지 않는다 (PRD 5절).
- **프레스티지바이오로직스는 매출 규모가 작아(125억 원) 소규모 계약도 공시 대상이 된다.** 수주 건수 비교 시 감안한다 (대시보드 S4 한계 문구).
- **정정 공시가 많다** (154건, 수주는 절반). 2019~2022년 계약의 금액 증액·공시 유보 기한 연장 같은 정정이 기간 안에 접수된 경우가 있어, 정정 공시의 접수일이 사건 시점은 아니다 (뉴스-공시 매칭 검수 결과, [AI_EVALUATION](../04_ai/AI_EVALUATION.md) 7절).
