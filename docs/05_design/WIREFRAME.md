## 1. 읽는 법

- 저해상도 배치도이다. 상자 크기는 비율만 뜻한다.
- `[F#]` 는 기능, `(US-##)` 는 스토리, `{AC-##}` 는 검수 기준이다.
- `⏳` 표시 요소는 데이터가 아직 없다 ([INFORMATION_ARCHITECTURE](INFORMATION_ARCHITECTURE.md) 7절). 데이터가 오기 전에는 4-1절의 "준비 중" 상태로 보여 준다. 2026-11-19 기준 남은 ⏳ 는 S2 "해외 CDMO 언급 수" 하나다.
- 화면 ID(S0~S6)와 필터 적용 범위는 INFORMATION_ARCHITECTURE 2·4절을 따른다.

## 4. 상태 표시

### 4-1. 공통 상태

| 상태 | 언제 | 표시 |
|---|---|---|
| 로딩 | 데이터 처음 읽을 때 (`st.cache_data` 전) | `st.spinner("데이터를 불러오는 중")` |
| 빈 결과 | 필터 조합에 해당하는 데이터가 0건 | 차트 자리에 "현재 필터에 해당하는 기사/공시가 없습니다" + [필터 초기화] 버튼. 빈 축을 그리지 않는다 |
| 준비 중 (⏳) | 산출물 파일이 아직 없음 | 회색 상자에 "준비 중 — ○○ 결과가 생성되면 표시됩니다". 오류로 보이지 않게 `st.info` 사용 |
| 데이터 오류 | 파일·DB를 읽지 못함 | `st.error` 에 파일 경로와 README 실행 순서 안내. 나머지 화면 요소는 계속 표시 |
| 신뢰도 낮음 | `cdmo_kw_basis='query'`, `input_basis` 가 제목만, 라벨 `confidence=low` | 행 옆에 작은 표시와 툴팁 |

### 4-2. 공시 Q&A 상태

| 상태 | 언제 | 표시 |
|---|---|---|
| 입력 전 | 처음 들어옴 | 예시 질문 버튼, 범위 안내 |
| 답변 생성 중 | 질문 제출 후 | `st.spinner("공시를 찾는 중")` |
| 답변 | 근거 공시가 있음 | 답변 + 근거 공시 목록 (근거 0개인 답변은 표시하지 않는다) |
| 거절 — 범위 밖 | 5개사 외 기업 (예: 론자) | `st.warning` "이 대시보드는 5개사 공시만 다룹니다" + 대상 기업 목록 |
| 거절 — 근거 없음 | 검색·생성·검증 단계에서 근거를 찾지 못함 | 오류로 읽히지 않게 경고 대신 `공시 근거 없음` 회색 배지 한 줄 + 질문 단어로 찾은 관련 뉴스 최대 5건을 정보 상자에("공시로 확인된 답은 아닙니다"). 뉴스도 없으면 질문을 바꾸는 방법 안내. 추측 답변을 쓰지 않는다 (2026-11-19) |
| 거절 — 판단 요구 | 투자 판단 등 | `st.info` "판단은 하지 않고 공시 사실만 안내합니다" |
| 인과 미확인 | 정책–수주처럼 관계를 묻지만 공시에 적혀 있지 않음 | 답변 아래 "인과는 공시로 확인되지 않음" 문구 |
| 오류 | API 키 없음·호출 실패 | `st.error` "Q&A를 사용할 수 없습니다(설정 확인)". 다른 화면은 정상 동작 |
