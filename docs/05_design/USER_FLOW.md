## 1. 대표 시나리오 — 미국 공급망 정책이 국내 CDMO에 주는 기회

> "미국의 바이오 공급망 정책이 변화하고 있다는 뉴스를 접했다. 이 정책이 국내 CDMO 기업에 어떤 기회를 제공하는지 파악하기 위해 관련 뉴스를 검색하고, 경쟁사의 생산시설 투자 및 수주 현황을 비교한 뒤, DART 공시를 통해 실제 사업 변화가 있었는지 확인한다." ([PERSONA](../01_product-strategy/PERSONA.md) 6절)

```
[S0 요약] ─①─▶ [S2 규제·정책] ─②─▶ [S1 이슈·트렌드] ─③─▶ [S4 기업 비교] ─④─▶ [S5 뉴스-공시 연계] ─⑤─▶ [S6 공시 Q&A] ─⑥─▶ [S0 요약]
  결론 확인       정책 기사 흐름         급증 시점·대표 기사      경쟁사 공시 비교       같은 시기 공시 확인        원문 근거 질의         근거 붙은 결론 정리
```

## 4. 유의점

- 1절 0~6단계의 화면 이동은 모두 구현돼 있지만, **2단계에서 5단계로 이슈를 이어 주는 L4가 없어** 사용자가 S5에서 이슈(키워드 × 기업 × 월)를 직접 다시 골라야 한다.
- L1로 들어오면 사이드바 필터가 카드 태그로 바뀐다. 다른 화면으로 옮겨도 그 필터가 유지되므로, 시나리오를 끝낼 때 "필터 초기화"를 누르는 것이 안전하다.
- 기업 필터(U2)·카드 거르기(U1)·S6 카테고리 미적용(U4)은 팀 확인 전 제안대로 동작한다 ([DECISIONS](../07_project-management/DECISIONS.md) D-31).
