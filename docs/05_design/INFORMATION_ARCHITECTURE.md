|---|---|

## 3. 화면 계층

Streamlit 멀티 페이지(`st.navigation`)로 구성한다. 사이드바 위쪽에 메뉴, 아래쪽에 공통 필터를 둔다.

```
사이드바
├── [메뉴]
│   ├── 요약                         S0  ← 시작 화면
│   ├── 산업 흐름
│   │   ├── 이슈·트렌드              S1
│   │   ├── 규제·정책                S2
│   │   └── 기술·생산                S3
│   ├── 경쟁
│   │   └── 기업 비교                S4
│   └── 근거 확인
│       ├── 뉴스-공시 연계           S5
│       └── 공시 Q&A                 S6
└── [공통 필터 F7]
    ├── 기간     (기본: 2023-10-19 ~ 2026-10-19 전체)
    ├── 기업     (기본: 5개사 전체, 다중 선택)
    ├── 카테고리 (기본: CDMO 키워드 6개 전체, 다중 선택)
    └── 필터 초기화
```

메뉴 묶음은 페르소나 대표 시나리오의 순서(정책 흐름 → 급증 시점 → 경쟁사 비교 → 공시 확인 → 질의 → 결론)를 따른다 ([PERSONA](../01_product-strategy/PERSONA.md) 6절).

화면 안의 하위 구분은 탭(`st.tabs`)으로 한다. 탭 구성은 [WIREFRAME](WIREFRAME.md)에 있다.

## 4. 공통 필터 (F7)

### 4-1. 필터 항목

| 필터 | 값 | 기본값 | 데이터 컬럼 |
|---|---|---|---|
| 기간 | 시작일·종료일 (일 단위) | 2023-10-19 ~ 2026-10-19 | `news.published_date`, `disclosures.rcept_date` |
| 기업 | 삼성바이오로직스, SK바이오사이언스, 프레스티지바이오로직스, 에스티팜, 바이넥스 | 5개사 전체 | `news_companies` (`match_field IN ('title','body')`, PRD 4절), `disclosures.corp_code` |
| 카테고리 | CDMO 규제·정책, CDMO 지정학, CDMO 모달리티, CDMO 생산능력, CDMO 수주, CDMO 경쟁 구도 | 6개 전체 | `news_cdmo_keywords.keyword` |

필터 값은 `st.session_state` 에 두어 페이지를 옮겨도 유지한다.

### 4-2. 화면별 적용 범위

AC-18("필터를 바꾸면 **모든 차트**가 함께 바뀐다")을 지키기 위해 화면마다 세 필터가 어디에 반영되는지 정한다.

| 화면 | 기간 | 기업 | 카테고리 | 비고 |
|---|---|---|---|---|
| S0 요약 | 카드 목록 거르기 | 카드 목록 거르기 | 카드 목록 거르기 | 카드 문장은 사전 생성(N2)이라 필터로 다시 쓰지 않는다. 카드의 기업·키워드·기간 태그로 걸러낸다 (8절 U1) |
| S1 이슈·트렌드 | ✅ | ✅ | ✅ | 기업 필터는 기업 언급 기사에만 걸린다. 기업 언급이 없는 산업 기사 처리는 8절 U2 |
| S2 규제·정책 | ✅ | ✅ | 규제·정책·지정학 2개로 고정 | 화면 자체가 카테고리를 정한다. 사이드바 선택과 겹치는 키워드만 보이고, 겹치지 않으면 빈 상태 안내 |
| S3 기술·생산 | ✅ | ✅ | 모달리티·생산능력 2개로 고정 | S2와 같은 방식 |
| S4 기업 비교 | ✅ | ✅ | 공시 차트: 키워드 ↔ `event_class` 대응으로 거름 | 대응표는 NEWS_DISCLOSURE_MATCHING 3-3절. 대응 공시가 없는 키워드(규제·정책, 지정학) 처리는 8절 U3 |
| S5 뉴스-공시 연계 | ✅ | ✅ | ✅ (기사 쪽), 공시는 연결 결과를 따름 | `news_disclosure_links.csv` 의 `news_keyword` 로 거름 |
| S6 공시 Q&A | 검색 조건 기본값 | 검색 조건 기본값 | 적용 안 함 | Q&A는 차트가 아니다. 사이드바의 기간·기업을 질문 범위 기본값으로 보여 주고 사용자가 해제할 수 있다 (8절 U4) |

모든 화면 상단에 현재 필터 상태를 한 줄로 표시한다 (예: `2025-01-01 ~ 2026-10-19 · 삼성바이오로직스 외 1 · 카테고리 6개 전체`).

## 8. 결정 필요 (팀 확인 전 제안)

| # | 항목 | 제안 | 대안 |
|---|---|---|---|
| U1 | S0 요약 카드에 필터를 어떻게 적용하나 | 카드는 전체 기간 기준으로 사전 생성하고, 필터는 카드의 태그(기업·키워드·기간)로 **걸러내기만** 한다. 걸러져 카드가 없으면 "현재 필터에 해당하는 요약 없음" 표시 | 필터 조합별로 카드를 미리 생성 (조합 수가 많아 비현실적) |
| U2 | 기업 필터를 기업 언급이 없는 산업 기사에 어떻게 적용하나 | 기업을 **일부만** 고르면 기업 언급 기사만 보인다. 5개 전체(기본값)이면 산업 기사도 모두 포함 | 기업 필터와 별도로 "산업 전체 기사 포함" 체크박스를 둔다 |
| U3 | S4 공시 차트에서 대응 공시가 없는 카테고리(규제·정책, 지정학)를 골랐을 때 | 후속 창 대응표(수주, 증설, M&A·구조개편)를 쓰고, "정책 이후 사업 활동이며 인과가 아님" 문구를 표시 | 공시 차트에는 카테고리 필터를 적용하지 않고 그 사실을 안내 |
| U4 | S6 Q&A에 사이드바 필터를 적용하나 | 기간·기업을 질문 범위 기본값으로 보여 주고 해제 가능. 카테고리는 적용하지 않음 | Q&A는 필터와 완전히 분리 |
| U5 | F5를 한 화면으로 둘지 두 화면(S5, S6)으로 나눌지 | 두 화면 (2절 이유) | PRD 그대로 한 화면 + 탭 |
