## 1. 비전

> 바이오 CDMO 산업의 변화와 기업별 대응을 **근거 기반으로** 파악한다.

흩어진 뉴스와 공시를 하나의 흐름으로 이어, 사업전략 담당자가 "무슨 일이 일어났는가"에서 멈추지 않고 "실제 사업 활동으로 확인되는가"까지 한 번에 확인하게 한다.

## 2. Core Question

> "글로벌 바이오 CDMO 산업에서 지금 어떤 변화가 발생하고 있으며, 이러한 변화가 우리 기업의 사업 기회와 경쟁력에 어떤 영향을 미치는가?"

과제 공통 질문 "이 산업에서 지금 무슨 일이 일어나고 있으며, 그 판단의 근거는 무엇인가."를 CDMO 실무자 관점으로 구체화한 것이다.

## 3. 영역별 핵심 질문

| 구분 | 핵심 질문 | 관련 대시보드 기능 |
|---|---|---|
| 산업 동향 | 현재 글로벌 바이오 CDMO 산업에서 가장 중요한 이슈는 무엇인가? | 핵심 이슈 및 뉴스 트렌드 |
| 정책·규제 | 국내외 정책 및 규제 변화가 CDMO 산업에 어떤 영향을 미치는가? | 규제·정책 모니터링 |
| 기술·생산 | 어떤 모달리티와 생산기술이 성장하고 있으며, 기업들은 어떻게 대응하고 있는가? | 기술·생산능력 분석 |
| 시장·경쟁 | 기업별 수주, 생산시설 투자 및 경쟁 구도는 어떻게 변화하고 있는가? | 기업별 비교 및 경쟁사 분석 |
| 근거·의사결정 | 해당 이슈가 실제 기업의 사업 활동에 어떤 영향을 미쳤으며, 이를 뒷받침하는 근거는 무엇인가? | 뉴스-DART 공시 연계 및 AI 분석 |

## 4. Supporting Questions

1. 어떤 산업 이슈가 새롭게 부상하고 있는가?
2. 정책·규제 및 기술 변화는 무엇인가?
3. 경쟁사들은 생산능력과 수주 측면에서 어떻게 대응하고 있는가?
4. 뉴스에서 나타난 변화가 실제 공시와 사업 활동으로 확인되는가?
5. 향후 주목해야 할 기회와 위험 요인은 무엇인가?

| Supporting Question | 영역별 핵심 질문 | 대시보드 기능 |
|---|---|---|
| SQ1 새로 부상하는 이슈 | 산업 동향 | 핵심 이슈 및 뉴스 트렌드 |
| SQ2 정책·규제 및 기술 변화 | 정책·규제, 기술·생산 | 규제·정책 모니터링, 기술·생산능력 분석 |
| SQ3 경쟁사 생산능력·수주 대응 | 시장·경쟁 | 기업별 비교 및 경쟁사 분석 |
| SQ4 뉴스 변화의 공시 확인 | 근거·의사결정 | 뉴스-DART 공시 연계 및 AI 분석 |
| SQ5 기회와 위험 요인 | 전 영역의 종합 | 요약 화면 (기회·위험 카드) |

## 5. 제품 원칙

| 원칙 | 의미 |
|---|---|
| 결론 먼저 | 첫 화면 상단에 의사결정 관점의 결론(기회·위험)을 둔다 |
| 근거 없는 결론 금지 | 모든 이슈·요약 문장에 출처(뉴스 URL 또는 DART 링크)를 붙이고, 근거가 연결되지 않은 LLM 결과는 노출하지 않는다 |
| 뉴스와 공시의 연결 | 뉴스의 변화를 같은 기업·인접 시점의 공시로 확인할 수 있게 한다 |
| 미리 계산, 화면은 조회만 | LLM 분석 결과와 임베딩은 사전에 생성해 저장하고, 대시보드는 조회만 한다 |
| 한계를 드러냄 | 데이터 범위(국내 언론 중심, 제목만 있는 기사 등)와 분류 정확도를 화면·리포트에 밝힌다 |

## 6. 목표

### 6-1. 기본 목표 (과제 필수)

- [ ] 대상 산업과 분석 대상 기업을 선정하고, 대시보드의 사용자와 핵심 질문을 정의한다
- [ ] DART 공시를 API로 수집하고 뉴스와 함께 DB에 저장한다
- [ ] 뉴스·공시 EDA를 수행한다 (기사량·공시 건수 추이, 이슈 급증 시점)
- [ ] LLM으로 감성 분류 및 핵심 이슈 추출을 수행하고, 결과의 정확도를 표본 검수로 확인한다
- [ ] 공시 문서 기반 RAG 질의응답 기능을 구현하고, 답변에 근거 공시를 표시한다
- [ ] Streamlit 대시보드에 이슈 분석 화면과 공시 Q&A를 통합한다
- [ ] 대시보드 상단에 의사결정 관점의 결론을 제시한다

진행 상황은 [PRODUCT_ROADMAP](../02_product-requirements/PRODUCT_ROADMAP.md)에서 관리한다.

### 6-2. 심화 확장 (선택)

| 항목 | 내용 |
|---|---|
| 주가·거래량 연계 | 이슈 발생 시점과 주가·거래량 변화를 시계열로 비교 |
| 뉴스 본문 보강 | 제공 기사의 원문을 크롤링하여 본문 기반 분석으로 확장 |
| 이슈 자동 요약 리포트 | 기간별 핵심 이슈를 LLM으로 요약하는 패널 구성 |
| 검색 고도화 | Text2SQL, 하이브리드 검색 적용 및 전후 비교 (Reranker는 과제에서 권장하지 않음) |
| 글로벌 범위 확대 | 지정학 외 이슈(모달리티·수주 등)도 해외(영어) 뉴스로 보강 — 현재는 지정학만 보강함 |

## 7. 범위 밖 (Non-goals)

- 실시간 뉴스·공시 수집과 실시간 LLM 분석 (대시보드는 저장된 결과만 조회)
- 비상장 CDMO(롯데바이오로직스, SK팜테코 등)의 공시 비교 — DART 정기공시가 없음
- 해외 CDMO(론자, 우시 등)의 공시 비교 — 뉴스 언급으로만 다룸
- 산업 보고서, 경쟁사 홈페이지 수집
- 투자 판단(매수·매도) 권고
