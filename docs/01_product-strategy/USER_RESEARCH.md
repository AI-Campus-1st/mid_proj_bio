# 사용자 조사

> **상태:** 작성 완료(가설 단계) · **최종 갱신:** 2026-11-13
> **원본:** `docs/dashboard_questions.md` 2·7절, `docs/news_sort.md`, `docs/data_schema.md`
> **관련 문서:** [PERSONA](PERSONA.md) · [PRD](../02_product-requirements/PRD.md)

---

> **주의:** 실제 사용자 인터뷰나 설문은 아직 하지 않았다. 이 문서의 사용자 니즈는 조에서 정의한 페르소나와 과제 요구사항에서 도출한 **가설**이며, 데이터로 확인한 사실은 별도로 표시한다. 검증 계획은 5절에 있다.

---

## 1. 조사 목적

- 페르소나(CDMO 사업전략·기획 담당자)가 실제로 어떤 정보를 어디서 얻고, 무엇이 불편한지 정리한다.
- 그 니즈를 우리가 가진 데이터(뉴스·공시)로 얼마나 충족할 수 있는지 확인한다.

## 2. 조사 방법

| 방법 | 내용 | 상태 |
|---|---|---|
| 데스크 리서치 | 과제 가이드, CDMO 산업 이슈(조에서 정한 6개 키워드)를 바탕으로 페르소나·Pain Point 정의 | 완료 |
| 데이터 탐색 | 수집한 뉴스·공시로 페르소나의 질문에 답할 수 있는지 확인 (아래 4절) | 완료 |
| 사용자 인터뷰 | 업계 실무자 대상 | 미실시 |
| 사용성 테스트 | 대시보드 시제품으로 시나리오 수행 | 미실시 (대시보드 구현 후) |

## 3. 사용자 니즈 가설

| # | 가설 | 근거 | 연결 Pain Point |
|---|---|---|---|
| H1 | 담당자는 뉴스·공시·보고서를 각각 따로 찾아본다 | 페르소나 정보 탐색 방식(뉴스 검색, DART, 산업 보고서, 경쟁사 홈페이지) | P1 |
| H2 | 기사 한 건만으로는 산업·기업 영향을 판단하기 어렵다 | 같은 사건이 여러 매체·제목으로 반복 보도됨 (중복 판정 규칙이 필요했던 이유) | P2 |
| H3 | 경쟁사 비교는 공시 기준으로 해야 객관적이다 | 수주·증설·M&A 공시는 유형이 정해져 있어 기업 간 같은 축으로 셀 수 있음 | P3 |
| H4 | 경영진 보고에는 "뉴스에서 봤다"보다 공시 근거가 필요하다 | 페르소나 업무: 사업전략 수립을 위한 근거 자료 작성 | P4 |
| H5 | 지정학(미국 생물보안법·관세 등) 이슈는 해외 보도를 봐야 흐름을 알 수 있다 | 국내 언론 중심 데이터로는 정책 출발점이 약함 → 해외(영어) 뉴스 보강 | P2 |

## 4. 데이터로 확인한 사실

니즈에 답할 데이터가 실제로 있는지 확인한 결과이다.

| 확인 항목 | 결과 | 출처 |
|---|---|---|
| 뉴스와 공시를 같은 기간으로 맞출 수 있는가 | 2023-10-19 ~ 2026-10-19로 뉴스·공시 모두 정렬 | `docs/data_schema.md` |
| 경쟁사 공시를 같은 축으로 비교할 수 있는가 | 5개사 공시 867건에 `event_class`(수주·증설·M&A·실적 등)와 가중치 부여 | `docs/company_selection.md`, `docs/data_schema.md` |
| CDMO 이슈별로 기사를 나눌 수 있는가 | 통합본 9,216건을 6개 키워드로 재분류 (규칙 기반, 정확도 미검수) | `docs/news_sort.md` |
| 제공 뉴스만으로 CDMO 이슈를 볼 수 있는가 | **부족함.** 제공 뉴스의 91%(2,543건)가 CDMO와 무관 → 기업명·CDMO 키워드·해외 검색으로 보강 | `docs/news_sort.md` |
| 해외 동향을 볼 수 있는가 | 지정학 이슈만 영어 뉴스 797건으로 보강. 다른 이슈는 국내 언론 중심 | `docs/news_sort.md` |
| 본문 기반 분석이 가능한가 | 제공·팀원 수집 뉴스만 본문 있음. 구글 뉴스 수집분(5,118건)은 제목만 | `docs/data_schema.md` |

## 5. 검증 계획

| 단계 | 방법 | 확인할 것 | 시점 |
|---|---|---|---|
| 1 | 조원이 페르소나 역할로 대표 시나리오 수행 | 6단계를 대시보드 안에서 끝낼 수 있는가 | 대시보드 1차 구현 후 |
| 2 | 처음 보는 사람(다른 조·강사)에게 첫 화면만 보여줌 | 결론을 이해하는가 (과제 Day 7 확인 사항) | 발표 전 |
| 3 | (가능하면) 업계 실무자 의견 | H1~H5가 맞는가, 빠진 질문은 없는가 | 선택 |

검증 결과는 이 문서에 추가하고, 바뀐 내용은 [PERSONA](PERSONA.md)와 [PRD](../02_product-requirements/PRD.md)에 반영한다.
