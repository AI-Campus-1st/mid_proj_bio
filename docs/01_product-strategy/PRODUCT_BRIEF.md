## 1. 한 줄 요약

뉴스와 DART 공시를 하나로 묶어, 바이오 CDMO 사업전략 담당자가 **"지금 산업에서 무슨 일이 일어나고 있고, 그 근거는 무엇인가"** 를 한 화면에서 확인하는 Streamlit 대시보드.

## 2. 배경 — 과제 정의

| 항목 | 내용 |
|---|---|
| 과제 | AI 기반 뉴스·공시 분석을 통한 산업 이슈 탐색 및 의사결정 지원 시각화 (중간프로젝트) |
| 기간 | 7일 |
| 핵심 기술 | Python(Pandas·NumPy), 정규표현식, DART OpenAPI, LLM API, LangChain, VectorDB, Plotly, Streamlit |
| 최종 산출물 | Streamlit 대시보드(이슈 분석 + 공시 Q&A 통합), PDF 리포트, PPT 발표 |
| 과제 공통 질문 | "이 산업에서 지금 무슨 일이 일어나고 있으며, 그 판단의 근거는 무엇인가." |

과제는 데이터 수집부터 분석, AI 활용, 시각화까지 한 흐름으로 수행한다.

| 단계 | 수행 내용 |
|---|---|
| 데이터 수집·DB화 | DART OpenAPI 기반 공시 수집, 뉴스·공시 통합 저장 |
| EDA·시계열 분석 | 기사량 추이, 이슈 급증 시점 탐지 |
| LLM·RAG | 이슈 추출·감성 분류, 공시 문서 질의응답 |
| 스토리텔링 시각화 | 의사결정 관점의 대시보드 구성 |

## 3. 산업과 분석 범위

### 3-1. 산업 선택 — 바이오 / CDMO

- **산업군:** 바이오 (과제가 제시한 6개 산업군 중 선택). 임상·허가 등 규제 이슈와 기술이전 공시의 연계가 명확하다는 점이 선택 이유이다.
- **세부 주제:** CDMO(위탁개발생산). 바이오 전반은 범위가 넓어, 수주·증설 공시로 사업 활동이 직접 확인되는 CDMO로 좁혔다.

### 3-2. 분석 대상 기업 — 5개사

| 기업 | 선정 근거 요약 |
|---|---|
| 삼성바이오로직스 | 수주 공시 22건, 본업 점수 110으로 모든 지표 1위. 비교의 기준점 |
| 프레스티지바이오로직스 | 수주 공시 15건, 가중 점수의 77%가 수주. CDMO 순도가 가장 높음 (매출 125억 원으로 소규모 계약도 공시 대상이 됨에 유의) |
| 에스티팜 | 수주 5건 + 실적 16건으로 수주 → 실적 흐름 확인 가능. 올리고핵산 원료 CDMO로 모달리티가 다름 |
| SK바이오사이언스 | 본업 점수는 낮으나 인수(타법인 주식 취득 2건)와 자체 백신 개발을 병행하는 사례로 다룸 |
| 바이넥스 | 가중 점수는 팬젠보다 2점 낮지만 본업 점수(24 대 20), 증설 공시 보유, 매출 약 12배로 유지 |

**선정 절차:** CDMO 사업을 하는 국내 상장사 14곳 → 자격 요건 3가지(G1 사업보고서 3건, G2 불성실공시 이력 없음, G3 수주 공시 3건 이상) → 공시 유형별 가중 점수 → 본업 점수·매출 규모를 함께 보고 확정. 비상장사(롯데바이오로직스, SK팜테코 등)는 DART 정기공시가 없어 제외했다.

> 가중치 표, 14개사 전체 결과, 한계는 `docs/company_selection.md` 에 있다. 데이터 문서 재편 시 `03_data/DART_DATA_SPEC.md` 로 옮길 예정이다.

## 8. 제약과 원칙

- **계층 분리:** 수집 → 재분류 → 적재 → 분석 → 대시보드. 대시보드는 API·LLM을 실시간 호출하지 않고 저장된 결과만 조회한다.
- **LLM 결과 검증:** 감성 분류·이슈 추출은 표본 검수로 정확도를 확인하고 기록한다.
- **근거 표시:** 공시 Q&A 답변에는 공시명·제출일·링크를 표시하고, 근거가 없으면 답변을 거절한다.
- **보안:** DART·LLM API 키는 `.env` 로 관리하고 저장소·발표자료에 노출하지 않는다.
