## 2. 감성 분류 — 표본 설계

| 항목 | 내용 |
|---|---|
| 모집단 | LLM 처리 범위와 같음: 대표 CDMO 키워드가 있고 중복이 아닌 기사 **4,727건** |
| 표본 크기 | **180건** (모집단의 약 3.8%) |
| 층 | 입력 유형 3개(본문 / 제목·한국어 / 제목·영어) × 대표 키워드 6개 = 18개 층 |
| 배분 | 층마다 최소 5건 + 나머지 90건은 층 크기에 비례 — 작은 층(예: 본문·지정학 79건)도 정확도를 볼 수 있게 |
| 추출 | 고정 시드 `20261116` 무작위 추출. 같은 DB에서 다시 실행하면 같은 표본이 나온다 |
| 독립성 | **LLM을 돌리기 전에** 뽑는다. 표본 파일에는 LLM 결과를 넣지 않는다 |
| 스크립트·파일 | `python analysis/sample_sentiment.py` → `data/eval/sentiment_sample.csv` |

## 3. 감성 분류 — 검수 절차

1. **표본 파일 열기:** `data/eval/sentiment_sample.csv` 를 엑셀이나 구글 시트로 연다. 각 행에 제목, 본문 앞부분(LLM 입력과 같은 1,500자), 매체, 날짜, 링크가 있다.
2. **독립 라벨링:** 검수자 2명이 [AI_CLASSIFICATION](AI_CLASSIFICATION.md) 2-2절 라벨 정의와 2-3절 판단 규칙에 따라 각자 `annotator_a`, `annotator_b` 에 `기회` / `위험` / `중립` 을 적는다.
   - 서로의 라벨과 LLM 결과를 보지 않는다.
   - LLM과 같은 조건이 되도록 링크를 열어 원문을 읽지 않고, 파일에 있는 제목·본문 앞부분만으로 판단한다.
   - 판단이 애매하면 `note` 에 이유를 적는다.
3. **합의:** 두 라벨이 같으면 그대로, 다르면 둘이 논의해 `label_final` 을 정한다. 합의가 어려운 사례는 `note` 에 남기고, 라벨 정의를 고칠 필요가 있으면 [AI_CLASSIFICATION](AI_CLASSIFICATION.md) 을 고친 뒤 프롬프트 버전을 올린다.
4. **LLM 라벨링:** 전체 4,727건을 LLM으로 분류해 `data/processed/sentiment_llm.csv` 에 저장한다 (형식은 [AI_CLASSIFICATION](AI_CLASSIFICATION.md) 2-6절). 표본 180건만 먼저 돌려 검수해도 된다.
5. **집계:** `python analysis/eval_sentiment.py` → `data/eval/sentiment_eval_result.md`
6. **기록:** 결과를 이 문서 4절에 옮기고, 오분류를 보고 프롬프트를 고쳤다면 버전별로 다시 집계해 비교한다.

| 지표 | 의미 |
|---|---|
| 검수자 간 일치율, Cohen's kappa | 정답 자체가 믿을 만한가. kappa 0.6 이상이면 대체로 일치, 0.8 이상이면 높은 일치로 본다 |
| 정확도 | LLM 라벨이 정답과 같은 비율 |
| 라벨별 정밀도·재현율·F1 | 어느 라벨을 잘못 붙이는가 (예: 중립을 기회로 과다 분류) |
| 혼동행렬 | 어떤 라벨끼리 헷갈리는가 |
| 유형별 정확도 | 본문 vs 제목만, 한국어 vs 영어, 키워드별, 키워드 근거(`query`)별, LLM 확신도별 차이 |

> `eval_sentiment.py` 는 가짜 라벨로 계산을 검증했다(일치율 90%, kappa 0.85, 정확도 75%가 기대값대로 나옴). 실제 결과는 아직 없다.

## 5. 한계

- **표본 180건은 층별로 5~20건**이라 층 하나의 정확도는 오차가 크다. 층별 수치는 경향만 본다.
- **제목만으로 판단하는 기사가 약 74%** 이다. 사람도 제목만 보고 판단하므로 정답 자체의 불확실성이 크다. 검수자 간 일치도로 이를 함께 보고한다.
- **정답은 조원 2명의 판단**이며 업계 실무자의 판단이 아니다.
- DB를 다시 빌드해 기사 구성이 바뀌면 같은 시드라도 표본이 달라진다. 검수를 시작한 뒤에는 표본 파일을 다시 만들지 않는다. (`sample_sentiment.py` 는 라벨이 적힌 파일을 덮어쓰지 않고, `--force` 를 붙여야만 새로 뽑는다)
