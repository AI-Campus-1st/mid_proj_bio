## 1. 단계별 로드맵 (과제 7일 일정 기준)

|---|---|---|---|---|
| **Day 1** 기획 및 환경 구축 | 산업 선정, 대상 기업 선정, 대시보드 사용자·핵심 질문 정의 / DART 인증키 발급, 저장소 및 협업 규칙 수립 / 뉴스·공시 통합 스키마 확정 | 스키마와 역할 분담이 확정되어 있다 | — | 완료 (역할 분담 문서화는 미확인) |
| **Day 2** 공시 수집 및 데이터 적재 | DART OpenAPI 연동, 공시 목록·원문 수집 / 제공 뉴스 적재 | 뉴스와 공시가 DB에 적재되어 있다 | — | 완료 |
| **Day 3** 전처리 및 EDA | 텍스트 정제(정규표현식), 중복 기사 처리 / 기업별·일자별 기사량, 공시 건수 추이, 이슈 급증 시점 확인 | 이슈 급증 시점을 근거와 함께 제시할 수 있다 | F1 | 진행 중 — 중복 처리·CDMO 재분류 완료, EDA 미착수 |
| **Day 4** AI 기반 이슈 추출 | 프롬프트 설계, 감성 분류 및 이슈 키워드 추출 / 표본 검수로 LLM 분류 정확도 확인 | 분류 결과와 검수 결과가 존재한다 | F1, F2, F3, F8 | 미착수 |
| **Day 5** RAG 공시 Q&A 구축 | 공시 문서 청킹·임베딩, 벡터 DB 구축 / LangChain 기반 질의응답, 근거 공시 표시 | 근거 공시와 함께 답변한다 | F5 | 미착수 |
| **Day 6** 대시보드 구현 | 이슈 트렌드·감성 추이 차트, 필터(기간·기업·카테고리) / 공시 Q&A 통합 | 필터가 모든 차트에 반영된다 | F1~F7 | 미착수 |
| **Day 7** 고도화 및 발표 | 스토리텔링 구성, 결론 문장 정리 / LLM 활용 한계(환각 등)와 대응 회고, 리포트 및 발표 | 처음 보는 사람이 결론을 이해할 수 있다 | F6 | 미착수 |

Day 4와 Day 5는 서로 독립적이므로 Day 3 이후 나누어 병행할 수 있다.
