| **Day 4** AI 기반 이슈 추출 | 프롬프트 설계, 감성 분류 및 이슈 키워드 추출 / 표본 검수로 LLM 분류 정확도 확인 | 분류 결과와 검수 결과가 존재한다 | F1, F2, F3, F8 | **완료 기준 충족** — 감성 분류 전체 4,727건과 표본 180건 검수(정확도 85.0%, 2026-11-17, [AI_EVALUATION](../04_ai/AI_EVALUATION.md) 4절). 이슈 키워드 추출 4,727건(실패 0)·이슈 이름 묶기(3,581개 → 2,706그룹) 완료, 이슈 추출 표본 30건 검수(층 가중 이름 98.7%·유형 97.4%·묶기 98.7%, 2026-11-18). 모달리티 태깅 4,727건(표본 80건 검수 정밀도 91.7%)·영어 제목 번역 797건 완료(품질 검수 전) (2026-11-18) |

| **Day 6** 대시보드 구현 | 이슈 트렌드·감성 추이 차트, 필터(기간·기업·카테고리) / 공시 Q&A 통합 | 필터가 모든 차트에 반영된다 | F1~F7 | **종료 조건 충족** (필터가 모든 차트에 반영 — 7화면 × 필터 18조합 자동 점검 오류 0건, [TEST_PLAN](../07_project-management/TEST_PLAN.md) 2절) — S0~S6 7개 화면 구현(이슈 트렌드·감성 추이 차트, 사이드바 필터, 공시 Q&A 통합, S0 결론·카드). 남은 것: 부상 이슈 증가율(미결 Q6), 연결 없는 기사 비율(Q12), 해외 CDMO 언급(Q7), UI 명세 U1~U5 팀 확인 (2026-11-18) |
| **Day 7** 고도화 및 발표 | 스토리텔링 구성, 결론 문장 정리 / LLM 활용 한계(환각 등)와 대응 회고, 리포트 및 발표 | 처음 보는 사람이 결론을 이해할 수 있다 | F6 | 미착수 |

Day 4와 Day 5는 서로 독립적이므로 Day 3 이후 나누어 병행할 수 있다.
