# 대시보드 사용자와 핵심 질문 — 바이오 CDMO

대시보드를 누가, 무엇을 판단하려고 쓰는지 정하고, 각 질문이 어느 화면과 어느 데이터로 답해지는지 확인한다.
화면 설계와 구현은 이 문서를 기준으로 하며, 마지막 절의 점검표로 반영 여부를 확인한다.

- **데이터 기준:** `docs/data_schema.md` (2023-10-19 ~ 2026-10-19, 5개사, 뉴스 8,419건·공시 867건)
- **대상 기업:** 삼성바이오로직스, SK바이오사이언스, 프레스티지바이오로직스, 에스티팜, 바이넥스 (`docs/company_selection.md`)

---

## 1. 대시보드의 최종 목적

바이오 CDMO 산업의 변화와 기업별 대응을 **근거 기반으로** 파악한다.

> **Core Question**
> "글로벌 바이오 CDMO 산업에서 지금 어떤 변화가 발생하고 있으며, 이러한 변화가 우리 기업의 사업 기회와 경쟁력에 어떤 영향을 미치는가?"

과제 공통 질문 "이 산업에서 지금 무슨 일이 일어나고 있으며, 그 판단의 근거는 무엇인가."를 CDMO 실무자 관점으로 구체화한 것이다.

---

## 2. 사용자 (페르소나)

### 사용자 정의

**바이오 CDMO 기업의 사업전략·기획 담당자.** 국내외 바이오 CDMO 기업에서 사업전략, 시장분석, 경영기획 업무를 수행한다. 글로벌 CDMO 산업의 정책·규제·기술·생산·수주·경쟁 동향을 지속적으로 모니터링하고, 이를 바탕으로 기업의 중장기 사업 방향과 경쟁전략을 수립한다.

### 페르소나 예시

| 항목 | 내용 |
|---|---|
| 직무 | 국내 중견 바이오 CDMO 기업 사업전략팀 과장 |
| 경력 | 바이오·제약 업계 8년 |
| 업무 | 글로벌 시장 조사, 경쟁사 분석, 경영진 보고자료 작성 |
| 정보 탐색 방식 | 뉴스 검색, DART 공시, 산업 보고서, 경쟁사 홈페이지 |
| 주요 불편 | 정보가 분산되어 있고, 뉴스와 실제 기업 사업 활동 사이의 연결 관계를 파악하기 어려움 |

### 주요 업무

- 글로벌 CDMO 산업 동향 모니터링
- 경쟁사 사업전략 및 투자 동향 분석
- 국내외 정책 및 규제 변화 파악
- 생산능력 및 수주 시장 변화 분석
- 사업전략 수립을 위한 근거 자료 작성

### Pain Point와 대시보드의 대응

| # | Pain Point | 대시보드의 대응 |
|---|---|---|
| P1 | 뉴스와 공시 정보가 여러 채널에 분산되어 있음 | 뉴스·공시를 통합 DB(`v_documents`) 하나로 모아 한 화면에서 같은 기준으로 조회 |
| P2 | 개별 뉴스가 산업 및 기업에 미치는 영향을 파악하기 어려움 | LLM 이슈 추출·감성 분류로 기사를 이슈 단위로 묶고, 영향 방향(기회/위험)을 표시 |
| P3 | 경쟁사별 사업 변화와 투자 동향을 비교하기 어려움 | 5개사의 수주·증설·M&A·자금조달 공시를 같은 축(`event_class`)으로 나란히 비교 |
| P4 | 산업 이슈를 객관적으로 뒷받침할 공시 근거를 찾는 데 시간이 소요됨 | 이슈마다 관련 공시를 연결하고, RAG 답변에 DART 원문 링크(`disclosures.url`)를 근거로 첨부 |

## 3. 핵심 질문과 대시보드 기능

### 3-1. 영역별 핵심 질문

| 구분 | 핵심 질문 | 관련 대시보드 기능 |
|---|---|---|
| 산업 동향 | 현재 글로벌 바이오 CDMO 산업에서 가장 중요한 이슈는 무엇인가? | 핵심 이슈 및 뉴스 트렌드 |
| 정책·규제 | 국내외 정책 및 규제 변화가 CDMO 산업에 어떤 영향을 미치는가? | 규제·정책 모니터링 |
| 기술·생산 | 어떤 모달리티와 생산기술이 성장하고 있으며, 기업들은 어떻게 대응하고 있는가? | 기술·생산능력 분석 |
| 시장·경쟁 | 기업별 수주, 생산시설 투자 및 경쟁 구도는 어떻게 변화하고 있는가? | 기업별 비교 및 경쟁사 분석 |
| 근거·의사결정 | 해당 이슈가 실제 기업의 사업 활동에 어떤 영향을 미쳤으며, 이를 뒷받침하는 근거는 무엇인가? | 뉴스-DART 공시 연계 및 AI 분석 |

### 3-2. Supporting Questions

1. 어떤 산업 이슈가 새롭게 부상하고 있는가?
2. 정책·규제 및 기술 변화는 무엇인가?
3. 경쟁사들은 생산능력과 수주 측면에서 어떻게 대응하고 있는가?
4. 뉴스에서 나타난 변화가 실제 공시와 사업 활동으로 확인되는가?
5. 향후 주목해야 할 기회와 위험 요인은 무엇인가?

### 3-3. 질문 연결 관계

| Supporting Question | 영역별 핵심 질문 | 대시보드 기능 |
|---|---|---|
| SQ1 새로 부상하는 이슈 | 산업 동향 | 핵심 이슈 및 뉴스 트렌드 |
| SQ2 정책·규제 및 기술 변화 | 정책·규제, 기술·생산 | 규제·정책 모니터링, 기술·생산능력 분석 |
| SQ3 경쟁사 생산능력·수주 대응 | 시장·경쟁 | 기업별 비교 및 경쟁사 분석 |
| SQ4 뉴스 변화의 공시 확인 | 근거·의사결정 | 뉴스-DART 공시 연계 및 AI 분석 |
| SQ5 기회와 위험 요인 | 전 영역의 종합 | 요약 화면 (기회·위험 카드) |

## 4. 기능별 설계 — 질문, 화면 구성, 데이터

### ① 핵심 이슈 및 뉴스 트렌드 — 산업 동향 / SQ1

| 항목 | 내용 |
|---|---|
| 답하는 질문 | 지금 가장 중요한 이슈는 무엇이고, 무엇이 새로 부상하고 있는가 |
| 화면 구성 | 월별 기사량 추이(중복 제외), 이슈 급증 시점 표시, 기간별 상위 이슈 목록, 이슈별 대표 기사 |
| 분석 방법 | 기사량 시계열 + 변화점 탐지(`ruptures`), LLM 이슈 추출로 기사를 이슈 단위로 묶음, 직전 기간 대비 증가율로 "부상 이슈" 판정 |
| 데이터 | `news` (`dup_of IS NULL`), `news_keywords.category`, `cdmo_mention` |

### ② 규제·정책 모니터링 — 정책·규제 / SQ2

| 항목 | 내용 |
|---|---|
| 답하는 질문 | 어떤 정책·규제 변화가 있었고, CDMO 산업에 기회인가 위험인가 |
| 화면 구성 | 정책·규제 이슈 타임라인, 이슈별 감성(기회/위험) 분류, 관련 기업 언급 |
| 분석 방법 | `규제 및 정책` 카테고리 기사에 LLM 감성·영향 분류 |
| 데이터 | `news_keywords` (`category='규제 및 정책'`, 425건), 보조로 `data/raw/cdmo_규제_20261113.csv` |

### ③ 기술·생산능력 분석 — 기술·생산 / SQ2

| 항목 | 내용 |
|---|---|
| 답하는 질문 | 어떤 모달리티(항체, ADC, mRNA, 세포·유전자치료제, 올리고 등)와 생산기술이 성장하며, 기업은 어떻게 대응하는가 |
| 화면 구성 | 모달리티별 언급 추이, 기업 × 모달리티 히트맵, 증설 공시 목록 |
| 분석 방법 | LLM으로 기사·공시에서 모달리티·생산기술 태그 추출 |
| 데이터 | `news_keywords` (`category='기술 및 트렌드'`: R&D·특허), `disclosures` (`event_class='증설'`), `disclosure_documents` 원문 |

### ④ 기업별 비교 및 경쟁사 분석 — 시장·경쟁 / SQ3

| 항목 | 내용 |
|---|---|
| 답하는 질문 | 기업별 수주·생산시설 투자·경쟁 구도는 어떻게 변하고 있는가 |
| 화면 구성 | 5개사 수주·증설·M&A·자금조달 공시 건수 비교, 기업별 공시 타임라인, 수주 계약 금액 추이 |
| 분석 방법 | `event_class` 기준 집계, 수주 공시 원문에서 계약 금액·상대방 추출 |
| 데이터 | `disclosures` (`event_class`, `event_weight`), `disclosure_documents`, `v_company_daily` |

### ⑤ 뉴스-DART 공시 연계 및 AI 분석 — 근거·의사결정 / SQ4

| 항목 | 내용 |
|---|---|
| 답하는 질문 | 뉴스에 나온 변화가 실제 공시와 사업 활동으로 확인되는가, 그 근거는 무엇인가 |
| 화면 구성 | 기업별 기사량 vs 공시 시점 비교 차트, 이슈 ↔ 관련 공시 연결 목록, 공시 질의응답(RAG) 창 |
| 분석 방법 | 같은 기업·인접 시점의 뉴스와 공시 매칭, 공시 원문 기반 RAG 답변 + 출처 링크 |
| 데이터 | `v_company_daily`, `v_documents`, `disclosure_documents.text`(RAG 원천), `disclosures.url`(근거 링크) |

### ⑥ 요약 — 기회와 위험 요인 / SQ5, Core Question

| 항목 | 내용 |
|---|---|
| 답하는 질문 | 향후 주목해야 할 기회와 위험 요인은 무엇이며, 우리 기업에 어떤 영향을 주는가 |
| 화면 구성 | 첫 화면에 기회·위험 카드. 카드마다 근거 뉴스·공시 링크와 ①~⑤ 상세 화면으로 이동 |
| 분석 방법 | ①~⑤ 결과를 LLM으로 요약하되, 근거가 연결된 항목만 카드로 노출 |
| 데이터 | ①~⑤의 산출물 |

## 5. 사용 시나리오로 확인

> "미국의 바이오 공급망 정책이 변화하고 있다는 뉴스를 접했다. 이 정책이 국내 CDMO 기업에 어떤 기회를 제공하는지 파악하기 위해 관련 뉴스를 검색하고, 경쟁사의 생산시설 투자 및 수주 현황을 비교한 뒤, DART 공시를 통해 실제 사업 변화가 있었는지 확인한다."

| 단계 | 사용자 행동 | 대시보드 기능 | 해소되는 Pain Point |
|---|---|---|---|
| 1 | 미국 공급망 정책 관련 뉴스를 검색하고 흐름을 본다 | ② 규제·정책 모니터링 (타임라인, 기회/위험 분류) | P1, P2 |
| 2 | 정책 이후 기사량이 급증한 시점과 관련 이슈를 확인한다 | ① 핵심 이슈 및 뉴스 트렌드 (급증 시점) | P2 |
| 3 | 경쟁사의 생산시설 투자·수주 현황을 비교한다 | ④ 기업별 비교 및 경쟁사 분석 | P3 |
| 4 | 같은 시기 수주·증설 공시가 실제로 있었는지 확인한다 | ⑤ 뉴스-DART 공시 연계 (시점 비교, 연결 공시) | P4 |
| 5 | "정책 이후 수주 계약 내용은?"을 질의하고 원문 근거를 본다 | ⑤ 공시 질의응답(RAG) + DART 링크 | P4 |
| 6 | 기회 요인을 경영진 보고자료로 정리한다 | ⑥ 요약 (근거 링크가 붙은 기회·위험 카드) | P1~P4 |

시나리오의 모든 단계가 대시보드 기능으로 이어지며, 끝에서 근거 링크가 붙은 결론을 얻는다.

## 6. 반영 점검표

구현 후 아래 항목을 확인해 체크한다.

**사용자·질문 반영**
- [ ] 첫 화면에서 Core Question에 대한 답(기회·위험 요약)을 바로 볼 수 있다
- [ ] 영역별 핵심 질문 5개가 각각 하나 이상의 화면으로 답해진다 (①~⑤)
- [ ] Supporting Questions 5개가 각각 하나 이상의 화면으로 답해진다 (3-3 표)
- [ ] Pain Point P1~P4가 각각 해당 기능으로 해소된다 (2절 표)
- [ ] 5절 사용 시나리오를 처음부터 끝까지 대시보드 안에서 수행할 수 있다

**근거 제시**
- [ ] 모든 이슈·요약 문장에 출처(뉴스 URL 또는 DART 링크)가 붙어 있다
- [ ] RAG 답변은 공시 원문에서 찾은 근거와 링크를 함께 보여준다
- [ ] 근거가 연결되지 않은 LLM 결과는 요약 카드에 노출하지 않는다

**데이터 해석**
- [ ] 기사량은 중복(`dup_of`)을 제외하고 센다
- [ ] 기업 단위 분석은 `match_field IN ('title', 'body')` 만 쓴다
- [ ] 본문 기반 분석(감성 등)은 제공 뉴스(`origin='provided'`) 범위임을 화면에 표시한다

## 7. 한계와 보완 방향

| 한계 | 영향받는 질문 | 보완 방향 |
|---|---|---|
| 뉴스가 국내 언론(네이버·구글 뉴스 한국어) 중심이다 | "글로벌" 산업 동향 | **보완함:** CDMO 지정학 이슈(생물보안법, 의약품 관세, 미국·유럽 현지 생산)를 구글 뉴스 미국판(영어)으로 추가 수집해 797건 적재(`origin='google_global'`, `lang='en'`). 화면에는 한국어로 번역해 보여준다. 다른 이슈는 여전히 국내 언론 중심 |
| 분석 기업이 국내 상장 5개사다 | 시장·경쟁 (글로벌 경쟁 구도) | 론자·우시 등 해외 CDMO는 뉴스 언급으로만 다루고, 공시 비교는 5개사로 한정 |
| 모달리티·생산기술 분류 컬럼이 DB에 없다 | 기술·생산 | LLM 태깅 결과를 별도 테이블로 적재 |
